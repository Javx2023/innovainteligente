# Licencias de las tipografías

Las dos familias se sirven autoalojadas en formato WOFF2, subseteadas a los glifos
latinos necesarios para el español (incluye tildes, ñ, ü, ¿, ¡ y signos de puntuación).

## Poppins

- Licencia: **SIL Open Font License 1.1**.
- Titular: Indian Type Foundry.
- Uso: titulares, botones y etiquetas de marca (`--font-display`).
- Pesos incluidos: 400, 500, 600, 700 y 800.
- Nota: la copia local del sistema desde la que se generaron los WOFF2 no incluía el
  archivo de licencia. La licencia aplicable es la OFL 1.1 y la atribución corresponde a
  Indian Type Foundry. Si se redistribuye el proyecto, conviene añadir el texto OFL del
  paquete original de Poppins.

## Inter

- Licencia: **SIL Open Font License 1.1**.
- Titular: Rasmus Andersson.
- Uso: texto de interfaz, formularios y documentación (`--font-sans`).
- Formato incluido: fuente variable (pesos 400–700, eje óptico).
- Texto completo de la licencia: [`OFL-Inter.txt`](OFL-Inter.txt).

## Uso permitido

La OFL permite usar, estudiar, modificar y redistribuir las fuentes, incluso en productos
comerciales, siempre que no se vendan por separado y se conserve la atribución. No se
modificaron los archivos originales de las fuentes: solo se subsetearon para la web.
